# #463 — Publish the settled diagnostics and ABI contract

Gate 8. Read [contract.md](contract.md).
Depends on #459 and #462. The factory half of #463 is a separate task.

## Outcome

C/C++ and Rust expose the same settled build/accuracy/refusal contract.
Compatibility with older binaries is not required; version and layout
guards make incompatible combinations explicit.

## Sequence

1. Map all settled summary fields and iteration records to C representations.
   Distinguish certification status, historical/current measured accuracy,
   price-only IV-unmeasured status, best-effort unmet targets, and optional
   adaptive history. Done when each C++ field/meaning has an explicit
   disposition and no unsupported confidence interval is implied.
2. Use caller-owned copy-out: summary getter plus caller-buffer iteration
   copy with required-capacity reporting. Specify null/zero-capacity probes,
   insufficient capacity, absent history, and error behavior. No pointer may
   reference a temporary optional/vector.
3. Support table and solver handles consistently, including table-to-solver
   conversion. Keep the current C/Rust backend scope; this is not backend
   parity work.
4. Publish the coordinated ABI revision and update C/C++ declarations,
   conversion code, Rust bindings, and version/layout tests together.
   Remove detect_multiple_roots according to #459; do not introduce it as
   a new C toggle.
5. Align saved-table version/model/domain metadata and compact historical
   accuracy summaries with #459/#460. Loading recertifies monotonicity.
   Full adaptive iteration history remains optional and need not persist.

## Completion tests

Compile C and C++ consumers; run C API behavior tests and Rust layout/
integration tests. Cover adaptive success, strict failure, best-effort output,
manual/loaded absence of adaptive history, price-only IV-unmeasured status,
iteration ordering/sentinels, insufficient/null output buffers, table-to-solver
propagation, and copied diagnostics surviving source-handle destruction.

Inspect src/ffi/mango_c_api.h/.cpp, crates/mango-option-sys bindings and
tests/layout.rs, and crates/mango-option integration tests. Document ownership,
units, statuses, supported backend scope, and incompatible version behavior.
Close #463 only after both factory and ABI tasks are complete.
