# Frozen continuous B-spline characterization

These manual research workers were run on released base `e9e10221`.
They do not modify production fitting, factory policy, or certification.
The manifests were frozen before their respective outcome measurements.

`continuous_bspline` builds an ordinary public adaptive table, saves its exact
payload, and separately runs whole-domain physical monotonicity proof. Four
declared cases produced two `NegativeWitness` results (C0-CALL, C2-PUT) and
two public `NoViableSurface` build refusals (CS-PUT, CS-CALL). No execution
timeouts or narrowed published domains were used.

`constant_shift` reuses the frozen C0-CALL payload and replaces every raw-dollar
EEP coefficient with binary64(c−delta), retaining the existing floor/European
composition. The seven predeclared shifts all retain a rigorous negative
physical witness. Every candidate is also evaluated through public price,
Greek, and actual IV methods on the same 772 required rows with a frozen
independent-reference snapshot. No candidate meets the original criteria;
the bounded experiment stopped without enlarging the ladder.

Complete payloads, per-row observations, reference provenance, SHA256 manifests,
execution resources, scripts and reports are retained at:
